I work on one question:

> Did the system actually reason correctly, or did it just produce a right-looking answer?

Most of what I build is infrastructure for answering that honestly. Evals that measure
repeatability instead of a single score. Agents with scoped tools and audit trails.
Benchmarks that state their own limits.

Based in New Haven, CT.

## What I'm Building

| Project | What it does |
|---|---|
| **[evalseal](https://github.com/patibandlavenkatamanideep/evalseal)** <br/> `pip install evalseal` | Reproducibility receipts for LLM evals. Runs an eval N times, reports per-case flip rates with confidence intervals, and seals the result (including the judge prompt, rubric and model) into a hash-linked, Ed25519-signed ledger. |
| **[memoryops-ai](https://github.com/patibandlavenkatamanideep/memoryops-ai)** | Governed memory runtime for AI assistants: policy-before-storage, context admission, deletion proofs, leakage evals. |
| **[RealDataAgentBench](https://github.com/patibandlavenkatamanideep/RealDataAgentBench)** | Benchmark for LLM data-science agents across correctness, code quality, efficiency and statistical validity. 500 recorded runs, 14 models. |
| **[relayops](https://github.com/patibandlavenkatamanideep/relayops)** | Control plane for AI support agents: scoped routing, policy broker, approval queue, replay verification, human handoff. |
| **[trust-rag-finance](https://github.com/patibandlavenkatamanideep/trust-rag-finance)** | Evaluation-driven financial RAG assistant with hybrid retrieval, citations, groundedness checks and audit logging. |
| **[CostGuard](https://github.com/patibandlavenkatamanideep/CostGuard)** · **[Tether](https://github.com/patibandlavenkatamanideep/Tether)** | LLM cost and reliability proxy with circuit breakers and provider fallback. Durable execution with checkpoint and resume for long-running agents. |
